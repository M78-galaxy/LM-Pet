# LM-Pet

独立桌面宠物，不依赖 Obsidian。不要改 `/Users/galaxym78/Obsidian-pet`，那边的插件已经冻结。

本机开发：`npm start`。改了 `main.cjs` 或 `preload.cjs` 之后，先从菜单栏图标退出，再重新 `npm start`。

## 0.1.1

2026-10-25。四个角色：天魔练习室采访、2025不心动挑战、牵手、真爱降临。Mac 安装包是一份通用包，Intel 和 Apple 芯片都能装。牵手逛逛不在安装包里。

装过 0.1.0 的人要先退出，删掉 `~/Library/Application Support/LM-Pet/settings.json`，再打开，才能看到新角色。喂食次数和窗口位置会一起清掉。

说明见 [release-notes/v0.1.1.md](release-notes/v0.1.1.md)。安装包在本机的 `release/v0.1.1/`，不进这个仓库。
